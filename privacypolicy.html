2. Introduction and Scope

The RTIS Device Monitoring Dashboard/Mobile App is designed to monitor Real-Time Information System (RTIS) devices and the events received from these devices for the automatic acquisition of train movement data across Indian Railways.

The application also provides authorized users with access to analytical, operational, and performance reports generated from the received events.

This Privacy Policy describes the personal information collected or processed through the application, the purposes for which such information is used, applicable data-sharing practices, security safeguards, and the mechanism for raising privacy-related grievances.

This policy applies to users accessing the RTIS Device Monitoring Dashboard/Mobile App and covers personal data processed for user authentication, access management, session management, and application security.

3. Personal Data Collected and Its Purpose

The application processes the following categories of information for authentication, access control, security, and operational purposes:

3.1 Identity Data

  • HRMS ID: Used to identify authorized users and facilitate access to the RTIS Dashboard through the Single Sign-On (SSO) service provided by CRIS.

3.2 Contact Data

  • Mobile Number: Used for One-Time Password (OTP)-based authentication and the delivery of SMS alerts, where applicable.
  • Email Address: Not currently used by the application. It may be used in the future for email communications, subject to the implementation of the relevant functionality and applicable privacy requirements.

3.3 Authentication and Access Log Data

  • Login ID: Used to identify users and support authentication and access control.
  • Authentication Records: Records associated with user authentication, where generated, are maintained for security and access-management purposes.
  • User Activity and Access Logs: Records of relevant user activities and access to the application are maintained in log files for security monitoring, auditing, troubleshooting, and accountability.

The personal information described above is processed for authentication, access management, security, and related application functions. It is not intended to be used for purposes unrelated to the operation of the application, except where required or permitted by applicable law or authorized policy.

3.4 Cookies and Session Identifiers

  • Cookies: Used for secure, same-site connections, where applicable, to support secure communication between the user's browser and the application.
  • Session Identifiers: Used to maintain user sessions and preserve the application state across successive requests. These identifiers help ensure that access to authenticated functions remains associated with the relevant user session.

The application should use only those cookies and session identifiers necessary for its stated functionality and security requirements.

3.5 Analytics Tools and Device Identifiers

  • Analytics Tools: No analytics tools have been identified as being used by the application for this policy draft. Any collection of usage analytics or diagnostic information should be disclosed if such tools are implemented.
  • Device Identifiers for Push Notifications: No collection of device identifiers for push notifications has been confirmed. If push notifications are implemented, the relevant device identifiers and their purposes should be disclosed in this policy.

3.6 Device Permissions and Access to Information

The application's access to device features and information is described below. The actual permissions requested by the mobile application should be verified before publication.

  • Camera: No camera access has been identified as necessary for the stated application functions.
  • Microphone: No microphone access has been identified as necessary for the stated application functions.
  • Location: No location data collection has been identified as necessary for the stated application functions.
  • Contacts: No access to the user's contacts has been identified as necessary for the stated application functions.
  • Photos and Files: No access to the user's photos or files has been identified as necessary for the stated application functions.

If any of these permissions are required in the current or a future version of the application, the relevant purpose, scope of access, and associated data-handling practices should be disclosed appropriately.

3.7 Payment Information

The application is intended for RTIS device monitoring and reporting. No collection or processing of payment details has been identified for the functions described in this policy.

3.8 User Data and Purpose Limitation

Personal information is processed primarily to authenticate users, manage access, maintain sessions, deliver applicable OTPs and SMS alerts, and support application security and auditing. The collection and processing of personal data should be limited to what is necessary for these purposes, in accordance with applicable organizational policies and legal requirements.

4. Data Sharing and Disclosure

The RTIS application is not intended to share users' personal data with external applications or other internal applications or groups as part of its stated functionality.

Personal data is processed for the purposes described in this policy and is subject to applicable access controls and organizational security requirements. Any future sharing or disclosure of personal data, if required, should be carried out only where authorized and in accordance with applicable laws, regulations, and CRIS policies. This may include disclosures required by law or by a competent authority.

5. Security Safeguards

CRIS is committed to protecting personal data processed through the RTIS application against unauthorized access, disclosure, alteration, loss, or misuse.

As specified for the application, personal data is stored in encrypted form. Appropriate technical and organizational safeguards should be implemented and maintained to protect personal information throughout its processing lifecycle. These safeguards may include:

  • Encryption of stored personal data and, where applicable, data transmitted over networks.
  • Authentication and access controls to restrict access to authorized users.
  • Secure session management and protection of authentication mechanisms.
  • Maintenance and monitoring of relevant security and access logs.
  • Periodic review of security controls in accordance with applicable CRIS policies.

The implementation of individual safeguards should be consistent with the application's actual technical architecture and approved security practices.
